# 10 — Practical Projects

Complete, synthesizable designs with testbenches. Each project demonstrates
real-world techniques you'll encounter in FPGA development.

## Projects

| Project | Description | Key Concepts |
|---------|-------------|-------------|
| [SPI Master](spi_master/) | Full SPI controller with all 4 modes | FSM, shift register, clock generation |
| [UART Transceiver](uart_transceiver/) | Configurable baud-rate UART TX + RX | Baud generator, oversampling, FSM |
| [AXI4-Lite Slave](axi_lite_slave/) | Register bank with AXI4-Lite bus | Protocol handling, address decode |
| [Debouncer](debouncer/) | Button debounce + edge detection | Counter-based filtering |
| [PWM Generator](pwm_generator/) | N-bit PWM with dead-time insertion | Counter compare, complementary outputs |
